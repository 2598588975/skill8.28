# Zz AI 短剧

使用已整理的 Zz 工作流作为按需参考，把请求路由到最相关的文件。所有参考文件均按 UTF-8 读取。

## 中控调用口令

用户以“zz skill中控”“Zz Skill 中控”或“zz中控”作为调用口令时，视为明确调用 `$zz-ai-drama`，立即完整读取 `references/staged-project-controller.md`。

- 用户只说调用口令而没有项目内容：回复“Zz Skill 中控已就绪”，展示从零开始、指定阶段、资料接力、回退修订四种可复制入口；不要创建项目文件或擅自执行阶段 01。
- 调用口令后同时提供创意、阶段、附件或修改目标：自动识别入口模式，只执行当前一个阶段，并在完成后等待确认。
- 调用口令出现在讨论、引用或否定语境中，不视为启动；只有用户把它作为当前操作指令时才触发。

用户要求“按流程逐步做”“一次只调用一个 Skill”“每一步确认后推进”“写入项目阶段文件”或同义约束时，先完整读取 `references/staged-project-controller.md`，进入严格分阶段项目模式。该模式的阶段门禁、单 Skill 锁和项目文件规则覆盖下方普通路由；不要在同一轮连续执行多个阶段。严格模式允许从零开始、指定阶段直达、以上传资料接力或回退修订，不得强迫用户补跑与当前目标无关的上游阶段。

## 工作方法

1. 判断任务属于创作、分析、资产、分镜、场景、角色或拉片。
2. 完整读取对应参考文件；不要只读取 YAML 描述或局部标题。
3. 普通模式下，若任务跨阶段，先建立共享的角色、场景、道具和视觉不变量，再按制作顺序调用参考文件；严格分阶段项目模式不得在同一轮跨阶段执行。
4. 保留用户已确认的剧本事实、人物身份、服装、空间关系、光线方向和道具状态。
5. 按所选参考文件的输出格式交付；用户明确要求解释、精简或改格式时再调整。
6. 参考文件提供方法与模板，不代表自动调用生图、生视频或剪辑服务。需要生成媒体时，继续调用当前环境中相应的生成 Skill 或工具。

## 跨阶段顺序

默认生产顺序：

`编剧/改编 → 剧本分析 → 资产 DNA → 标准 @资产库 → 角色与场景专项资产 → 分镜脚本 → 故事板/九宫格 → 视频生成 → 拉片复核`

若用户已有成熟剧本，可从剧本分析或资产 DNA 直接开始；若只有参考视频，则从拉片开始，再决定是否进入原创改编与重制。

## 严格分阶段项目模式

严格模式只负责识别入口模式、登记权威输入、选择当前阶段的一个工作 Skill、维护 `project-state.md` 与依赖索引、写入当前阶段文件并等待确认。阶段映射、文件名、Word 人工修改回路、版本规则、局部失效分析与回退规则见 `references/staged-project-controller.md`。

在该模式中，“总控路由”不算内容生产 Skill；每个内容生产轮次最多选择一个工作 Skill。普通文件读写和格式校验不算额外工作 Skill，但处理 DOCX 时必须把 `documents` 作为该轮唯一工作 Skill。阶段完成后必须停在 `awaiting_confirmation`，不得预写下一阶段内容。

## 统一身份

本 Skill 只以 `Zz AI 短剧` 和 `$zz-ai-drama` 作为显示名与调用身份。导入参考中的旧昵称、旧调用名或强制署名要求均不参与触发，也不得作为回复中的自称。
