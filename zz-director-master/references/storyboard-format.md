# 基础分镜格式

> 默认格式。目标是清楚、可复制、可计算，不附统一规则页或通用负面提示词。复杂连续性项目另读 `production-locks.md`。

## 一、三行镜头块

每个剪辑点对应一个镜头块，镜头之间空一行：

```text
镜头：01｜00:00-00:04｜低机位·大特写｜必要焦段｜贴水缓慢前移
场景：清晨海岸。浪花越过湿沙上的贝壳；潮水退去，贝壳缺口与天然色带留在晨光里。
声音：近岸潮声、细沙回流；旁白：“潮水退去，海把光留在贝里。”
```

### `镜头：`

顺序为 `编号｜起止时间码｜角度·景别｜必要焦段｜主要运镜`。

- 镜号连续；多场项目可统一使用`集-场-镜`编号。
- 时间码使用 `MM:SS-MM:SS`，相邻镜头首尾相接。
- 焦段只在会改变透视、景深或人物关系时写。
- 每镜只保留一个主要运镜；独立机位或切镜另起镜号。

### `场景：`

顺序为 `空间/时段 + 主体与环境 + 可见动作/表演 + 关键细节 + 结束状态`。

- 不用情绪标签代替呼吸、视线、重心、手部或身体反应。
- 身份、服装、道具或位置只有在本镜需要辨认或发生变化时才写。
- 结束状态要足以让下一镜继续，不重复全局人物和风格设定。

### `声音：`

- 保留确认过的说话者和台词，以及必要环境音、动作音效和配乐。
- 没有关键声音时可写简短环境声；不为完整格式而堆配乐说明。

## 二、镜头粒度与时长

- 推、拉、摇、移和焦点变化发生在同一连续画面内时不增加镜号。
- 硬切、跳切、叠化后出现新画面时增加镜号。
- 常规镜头以 3-5 秒为参考；单一信息 2-3 秒，复杂动作或情绪落点 6-10 秒。
- 超过 15 秒的镜头需要清楚的内部动作变化；包含多个独立机位时拆成镜头组。
- 交付前检查总时长、断档和重叠。

## 三、必要信息原则

基础稿只保留：镜号、时间码、角度与景别、主要运镜、可见画面、明确结束状态和可听声音。

以下内容默认不进入基础稿：

- 逐镜叙事目的、常规备注和重复技术说明。
- 全片统一规则、角色设定复述和通用负面提示词。
- 不改变画面结果的器材参数、装饰性术语和空泛质量要求。

某镜确有连续性或生成风险时，切换到增强格式的单镜控制模块，不在基础稿后附整套规则。

## 四、DOCX 输出

- 默认使用无表格 DOCX，每镜为真实段落，便于逐镜复制。
- 文件名：`[项目名称]_AI视频复制执行稿_[总时长].docx`。
- `镜头：`加粗或轻量强调；`场景：`和`声音：`使用正文样式。
- 镜头块之间留空行或等效段后距；场景标题不打断镜头块。
- 不添加统一规则页、负面词页、空白备注页或与执行无关的说明页。

## 五、旧版九列表格

只有用户明确要求“九列分镜表”“xlsx”或制片统计时，才使用：

`镜号 / 时长 / 摄影角度 / 景别 / 画面内容 / 场景 / 声音 / 备注 / 叙事目的`

表格仍需保持镜号连续、时间码无断档、画面内容可拍摄。
