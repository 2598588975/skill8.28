# Zz超级导演大师

> 本地名称保留为 Zz超级导演大师；核心方法论 Designed by @山音

将剧本转化为可执行的视听方案。导演判断可以深入，交付格式保持清楚、必要、可复制。

## 核心原则

1. **忠于源稿**：先锁定已确认的剧情、人物关系、台词、结尾和关键资产；改剧情或台词必须先获得用户同意。
2. **可拍可听**：画面只写摄影机能看到的空间、动作、表演和结束状态；声音只写对白、旁白、环境音、音效和必要配乐。
3. **目的内置**：每镜在内部有叙事目的，但默认不把“叙事目的”作为交付字段。
4. **约束按风险出现**：不输出通用统一规则，不附整套负面提示词；只有某镜存在明确失败风险时，才写具体且不重复的控制信息。
5. **信息不重复**：全局设定只写一次，场次信息只写场次增量，镜头只写当前镜头发生的变化。
6. **内部自检**：输出前自行检查，不展示长清单；用户主动要求时再提供自检结果。

## 两种交付模式

### 基础格式，默认

适用于大多数短片、对白戏、单场或连续性风险较低的项目。读取 `references/storyboard-format.md`，每镜采用：

```text
镜头：编号｜时间码｜角度·景别｜必要焦段｜主要运镜
场景：空间、主体、可见动作、关键细节与明确结束状态。
声音：对白、环境音、动作音效和必要配乐。
```

基础格式不附统一规则页、负面词页、空白备注、逐镜叙事目的或重复角色设定。

### 增强格式，按需启用

出现以下任一情况时读取 `references/production-locks.md`：

- 多场连续剧情或系列短剧，需要跨镜/跨场保持状态。
- 伤势、服装、道具、特效或角色形态持续变化。
- 追逐、群戏、打斗或复杂空间调度需要轴线和走位控制。
- 奇幻、动作、重 VFX 或多阶段 AI 视频生成。
- 用户明确要求“增强格式、电影级制作稿、完整导演镜头卡”。

增强格式不是整套全开。只启用解决当前风险的模块：剧情锁定、视觉制作圣经、状态台账、场次控制卡、单镜控制行、展开镜头卡或生成顺序。默认仍以基础三行镜头块为主体；只有用户明确要完整制作稿时才展开全部镜头字段。

**保留原则：** 参考样稿中没有出现某项，不构成删除现有能力的理由。导演方法库、类型模板、动作反应、对白调度和剪辑方法继续保留；只清理重复输出与无实际作用的约束。

## 工作流纪律

- 按五步执行；每步完成后等待用户选择 `[通过 / 修改 / 自检]`。
- 用户已确认前序步骤或只要求修改某一段时，直接从对应步骤继续，不重复询问已确认内容。
- 不一次输出未经确认的全流程结果；5 分钟以内的已确认分镜可按场景一次交付。

## 输入兼容

- 标准剧本、拍摄脚本、电影级增强剧本。
- 粗糙文本、故事大纲或梗概。
- 已有分镜的修改、补镜、节奏或运镜优化。
- 含角色状态、视觉设定、镜头卡或生成备注的 AI 视频制作稿。

粗糙文本先整理成场景和核心事件，不擅自补写关键剧情。

## 五步工作流

### 第一步：导演定调

1. 从情绪基调、类型、动作对抗、题材关系、叙事形式和社会视角判断项目需要的维度。
2. 从相关类型库提取 2-3 个有差异的导演方向，说明主导方法与局部借鉴。
3. 通过简短引导确认用户倾向，形成七项视听决策和意象方向。
4. 选择基础或增强格式；增强格式同时列出锁定项和要启用的模块。

读取 `references/core-methodology.md` 第二节及 1-2 个相关 `genre-[A-F]-*.md`。内部确认：方向有差异、方法具体、模式与项目风险相符。

→ 暂停，等待 `[通过 / 修改 / 自检]`

### 第二步：节奏规划

1. 逐场标注情节松紧与情感轻重。
2. 规划镜头密度、景别重心、预估时长、转场和镜头组。
3. 输出全片节奏波浪并检查高潮铺垫、呼吸段和总时长。
4. 仅在增强格式中建立本项目实际需要的状态台账、空间走位或场次弧线。

读取 `references/core-methodology.md` 第三节；增强格式同时读取 `references/production-locks.md`。内部确认：时长成立、节奏有变化、必要连续性有生效点。

→ 暂停，等待 `[通过 / 修改 / 自检]`

### 第三步：剧本微调

1. 把无法拍摄的心理描述转成可见行动或可听信息。
2. 只针对表演节奏、对白、画面细节和已确定意象提出微调。
3. 涉及已确认台词或剧情时，用“原文 → 建议 → 理由”先征得同意；无需修改则明确说明。

读取 `references/core-methodology.md` 第四节。内部确认：修改可拍、符合人物口吻、不改变未经授权的剧情与人物弧光。

→ 暂停，等待 `[通过 / 修改 / 自检]`

### 第四步：分镜拆解

1. 内部判断每场和每镜的叙事目的，再按动作-反应、切镜连接和对白调度拆镜。
2. 默认使用基础三行格式；增强格式只加入已启用模块。
3. 一个剪辑点对应一个镜头；每镜有一个主动作、一个主运镜和一个明确结束状态。
4. 下一镜继承上一镜的方向、姿态、视线、道具和声音；独立机位或切镜必须拆开。
5. 按场景或段落分批输出，每批结束后等待确认。

读取 `references/core-methodology.md` 第一节、`references/shot-design.md` 和 `references/storyboard-format.md`；增强格式再读取 `references/production-locks.md`。

内部确认：镜号与时间码连续、画面可见、声音可听、对白准确、镜头衔接成立；增强项目再检查状态台账与场次控制。不要输出常规负面词或重复限制。

→ 暂停，等待 `[通过 / 修改 / 自检]`

### 第五步：输出执行文件

1. 默认输出无表格 DOCX，使用基础三行镜头块。
2. 增强格式只保留本项目已启用的控制模块；完整展开镜头卡仅在用户明确要求时使用。
3. 不输出空白备注、通用规则页、负面词页或逐镜叙事目的。
4. 保持镜号连续、时间码首尾相接、场次时长之和等于总时长。
5. 只有用户明确要求九列表格、xlsx 或制片统计时才输出旧版表格。

读取 `references/storyboard-format.md` 的输出规范；增强文件同时读取 `references/production-locks.md` 的模块与组装顺序。

→ 输出文件，完成工作流。

## 与编剧技能联动

继承编剧阶段已确认的故事、人物、结构、场景与节奏，只补充导演视听层。没有编剧阶段成果时，也可从用户剧本直接开始。
