# 交付前质量检查

## 时间

- [ ] 所有镜头时间连续，无重叠、无空档；有黑场或停顿时显式计时。
- [ ] 每镜内部动作秒数之和等于该镜持续时间。
- [ ] 所有镜头时长之和等于目标时长与模型设置时长。
- [ ] 对白时间足以容纳正常语速，且没有与不可能同时完成的动作冲突。

## 资产

- [ ] 所有 `{{Node …}}` 引用存在且与节点连线/输入一致。
- [ ] 角色、道具、动物和武器数量明确，未在后续镜头无故增殖。
- [ ] 角色声线不会串给其他角色；画外音和画内对白已区分。
- [ ] 空引用、重复引用和仅有名称但无用途说明的资产已处理。
- [ ] 引用的实际节点类型匹配用途，图片未充当声线、音频未充当场景；同名资产按所属项目与状态变体区分。

## 空间与连续性

- [ ] 人物左右、朝向、路线、入口/出口和固定地标前后一致。
- [ ] 每镜起幅可由上一镜落幅到达；跳时、蒙太奇、闪回和转场均显式标注。
- [ ] 持物手、服装状态、湿身/伤势、破坏程度和道具位置连续。
- [ ] 未在越轴时无说明地交换屏幕方向。

## 镜头

- [ ] 摄影机栏只写焦段、机位、运动、构图、景深和速度感。
- [ ] 画面栏写可见动作，不用“高级、震撼、电影感”代替事件。
- [ ] 每镜有明确主体；多个并行动作使用“同时”绑定。
- [ ] 快切、升格、黑白冲击帧和运镜变化都有持续时间或明确触发点。
- [ ] 运镜写明起点、触发、路径、加减速与落幅；转焦与景深、摇摄与平移、变焦与前推没有混淆。
- [ ] 多视点展示同一动作时已注明连续承接或同步回看；运动距离、速度与成片时间相容。

## 动作与物理

- [ ] 每次攻击写清起点、轨迹、目标、接触点和结果。
- [ ] 双方都有受力或闪避反馈；动作结束后有分离状态。
- [ ] 环境破坏来自明确接触、攻击或余波，不凭空发生。
- [ ] 粒子、水、烟、衣料、头发和碎屑具备惯性、受力方向与消散方式。

## 表演与声音

- [ ] 视线目标、表情弧、重心和呼吸可执行，避免一次塞入多个矛盾情绪。
- [ ] 台词逐字准确，角色、语气、画内/画外和时间点齐全。
- [ ] 音效与动作节点同步，环境声有远近和方向。
- [ ] 用户要求无 BGM、无字幕、无水印时，成片要求和负向约束均有体现。
- [ ] 有意遮挡黑场、静默或固定机位未被通用负向词误禁；原文中错误引用与时间/方向冲突已校正。

## 最终报告

交付末尾用一行报告：

```text
校验：总时长 <x>s；镜头 <n> 个；资产引用 <n> 项；时长/坐标/数量/接戏检查均通过。
```

若未通过，不要伪称完成；指出具体镜号与冲突，并修正后再交付。
