# 统一提示词与秒级分镜格式

## 1. 项目头

```text
【项目】<名称>
【一句话剧情】<人物 + 目标 + 阻力 + 结果>
【目标时长】<总秒数>
【画幅/分辨率】<16:9、21:9、9:16 等>
【媒介】<真人实拍、3D 动画、二维动画等>
【摄影基底】<传感器感、焦段倾向、手持/稳定、景深、快门感>
【声音】<对白/环境声/拟音/BGM 开关>
【禁止】<字幕、水印、错误数量、跳轴等真正高风险项>
```

## 2. 资产表

每项同时说明“是什么”和“怎么用”。

```text
【角色】{{Node "角色A-全身设定"}}：身份、发型、服装、体态；锁定左右手、状态和声线。
【场景】{{Node "主场景"}}：入口、出口、前中后景、固定光源、可破坏区域。
【道具】{{Node "核心道具"}}：尺寸、材质、数量、初始持有者和允许的运动方式。
【声音】{{Node "角色A声线"}}：音色、年龄感、情绪范围；只用于角色A。
【首尾帧/视频】{{Node "首帧"}}：只锁起幅构图；是否允许重构镜头。
```

### 适合作为资产的常见格式

- 角色：全身/半身/三视图或四视图；背景干净、服装和比例一致。
- 场景：横向宽图，能读清入口、出口、层级、尺度和固定物件。
- 道具：单体、数量明确、轮廓完整；复杂武器补侧视或比例信息。
- 声音：每个角色单独的干净语音样本，避免混响和多人混声。
- 视频：作为首帧、尾帧、动作或连续性参考时明确用途，不要只写“参考视频”。

## 3. 全局规则

```text
【世界坐标】场景方向、地标和人物路线。
【屏幕方向】角色A始终由左向右；角色B初始位于高处/右侧。
【人物状态】伤势、服装湿度、情绪、可用肢体、持物手。
【数量锁定】角色、武器、动物和道具各自数量。
【物理规则】攻击、粒子、水、烟尘、破坏和受力怎样产生。
【特效规则】颜色、透明度、材质、速度、是否发光、消散方式。
【连续性】上一镜落幅如何成为下一镜起幅。
```

## 4. 秒级镜头模板

```text
镜头 <编号> | <起始–结束> | <持续秒数> | <景别/角度> | <切换方式>

【摄影机】
<焦段>；<机位高度与朝向>；<固定/推/拉/摇/移/环绕/跟拍>；<构图>；<景深与速度感>。

【起幅】
<主体在画面中的准确位置、朝向、重心、持物、前中后景关系>。

【画面】
<主体A动作、轨迹和目标>（x.xs）→ <接触/反应/受力>（x.xs）→ <主体B反动作与环境反馈>（x.xs）。

【人物表演】
<眼神目标>；<表情从何种状态变为何种状态>；<身体重心和呼吸>；<口型要求>。

【对白】
<角色>｜“<逐字台词>”｜<情绪和力度>｜<画内/画外>｜<时间点>
无台词时写：无台词。

【音效】
<动作拟音>；<环境底噪>；<声音远近和方向>；<是否无 BGM>。

【落幅/接戏】
<人物、道具、镜头和环境在镜尾的状态；下一镜不可违背的条件>。
```

## 5. 动作镜头示例

```text
镜头 03 | 00:06–00:10 | 4s | 中近景/贴地低机位 | 连续
【摄影机】35mm；贴地后拉跟拍；人物分居画面左右，保留进攻纵深；高速段使用方向性运动模糊。
【起幅】角色A在左侧前冲，右手持刀；角色B在右侧后撤，双脚仍接触石面。
【画面】A沿腰线横斩（0.7s）→ B下沉重心、前臂格开刀背，双方手臂向相反方向弹开（0.8s）→ A借反震转髋回收，B向前跨步肘击（0.9s）→ A侧身避开，肘风击中后方木栏，木栏向画面右后方折裂（0.8s）→ 两人重新拉开两米距离并锁定视线（0.8s）。
【人物表演】A咬紧牙关、视线锁住B肩线；B呼吸急促但表情克制。
【对白】无台词。
【音效】刀风、格挡钝响、鞋底摩擦、木栏折裂；无BGM。
【落幅/接戏】A仍在左侧且右手持刀；B右脚后撤，下一镜不得交换左右位置。
```

## 6. 对白镜头示例

```text
镜头 02 | 00:05–00:13 | 8s | 双人近景 | 硬切
【摄影机】50mm、T2.8；与桌面齐高；缓慢前推二十厘米；焦点先在角色A，再切至角色B。
【起幅】A在画面左侧靠窗，B在右侧靠外；杯子位于二人之间，A双手不接触杯子。
【画面】A垂眼听完问题，拇指轻压衣角（1.5s）→ 焦点切至B，B停下搅拌并抬眼（1.0s）→ A抬头说话，语速平缓（3.5s）→ B先惊讶后放松，轻点头回应（2.0s）。
【人物表演】A由回避视线转为直视；B的眉峰先抬起再回落，避免夸张表情。
【对白】A｜“我只是还没想好怎么告诉你。”｜克制、略带歉意｜画内｜00:07.5–00:11
【音效】杯勺轻碰、室内通风声、衣料摩擦；无BGM。
【落幅/接戏】A与B保持原座位，杯子未被拿起，下一镜可切B的反应特写。
```

## 7. 负向约束模板

只保留和当前内容直接相关的风险：

```text
【负向约束】人物身份互换、左右位置跳变、道具增殖、持物手改变、无接触破坏、动作无惯性、口型不同步、字幕、水印、BGM。
```
