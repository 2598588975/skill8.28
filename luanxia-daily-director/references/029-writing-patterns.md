# 029之围：重点提示词段与镜头写法

来源：2026-09-17 提取的《熵乱归序：029之围- 副本》《熵乱归序：029之围2- 副本》《熵乱归序：029之围3- 副本》。共60份非空视频提示词；完整来源与版本见 [索引](029-source-index.md)。仅分析文字和节点引用，未观看任何资产图或成片。以下“原段”是原文摘录，“提炼/模板”是整理后的写法，不表示视频已准确实现。

## 调用时怎么参考

写乱霞号风格的视频提示词时，先选择当前镜头的叙事任务：交代空间、转移注意、交接人物、追踪动作、呈现尺度或收束表演，再参考下方对应案例。不要为了复刻风格，把每镜都堆成极速环绕、荷兰角和冲击帧。

资产生成任务主要读第8节和 [资产生成原文](029-asset-prompts.md)。延续029角色剧情时按 [资产档案](029-assets.md) 查询所属项目与变体；写新故事时迁移方法，替换人物、设定和节点引用。完整提示词按索引定向查一两个案例，不默认加载三份全文。

## 1. 核心语法：让摄影机跟着事件做决定

原作常见句式：焦段与起幅 → “伴随/当/瞬间”触发 → 运镜路径与速度 → 焦点交接 → 稳定或带呼吸落幅。

整理后的摄影机段模板：

~~~text
【摄影机】<焦段>，机位位于<主体哪一侧、何种高度>，<景别>起幅，焦点锁定<具体对象>。当<动作/视线/声音触发>，机位以<加速/匀速/减速>沿<路径>移动至<终点机位>；在<时间或节点>把焦点由<前景A>转至<中/后景B>。最后<缓停/急停后衰减微震/静止>，落幅保留<构图与下镜信息>。
【画面】<动作起点>→<接触/显形/对话变化>→<身体与环境反馈>→<落幅状态>。
~~~

摄影机段和画面段分开是完整模式；P3后期也有“秒段标题写机位运镜、正文写动作”的紧凑模式。短段可以用紧凑模式，但不能省略动作触发、焦点对象、速度变化和镜尾状态。两种模式共享同一条时间线。

## 2. 日常长镜：以人物交接完成构图变化

### P1 / LX-4 / v-4Bhn2t1v8x：从前台转到同行三人

原段：

> 伴随晚照与乱雪从右侧前景入画，镜头执行平滑的景深切换（Rack Focus），将焦点拉回并锁定于前景两人，同时机位开始伴随两人的步伐进行绝对平稳的侧向平移跟拍（Lateral Tracking）。
> 当两人经过前台后，镜头机位平滑顺滑地向后方弧形摇移（Arc），自然过渡为侧后方的跟随跟拍（Following Shot），为云徽从后方追上并入画留出构图空间。

提炼：焦点先从中景交给进入前景的人，再侧移陪走，最后弧移到后侧，为第三人追上留出空间。每次机位变化都有接人或交代关系的用途。需要三人同清晰时另写景深范围，不把拉焦误当成景深扩大。

适用：走廊交谈、引路、汇合、前台离场。连续镜头保持焦段，提前写好追上者从哪一侧进入。

### P2 / SC2-1 / v-dFf3grbW40：随群众进入生存舱

原段：

> 跨越舱门进入内部后，随着四川男子的抬头观望，机位顺势执行慢速半环绕跟拍（Arc Shot），并配合辅助设备进行垂直拉升（Pedestal Up），将视角从拥挤的人群近景平滑抬高至俯瞰全景，利用35mm焦段自然展现生存舱庞大深邃的内部空间，稳定落幅。

提炼：人群中的低位贴身跟随建立压力；越门后以人物抬头为转折，再升高展示空间。先明确门槛、净空和摄影机路径；升起后是否仍属角色主观视角要写清，不能默默穿墙或穿人。

## 3. 视线与焦点：先让人看，再让观众看

### P1 / LX7.5 / v-AtZqhgkQwN：遮挡不抢焦，警报改变节奏

原段：

> 司联官与两个医疗机器人从极前景横向走过时，形成自然的物理前景遮挡（Foreground Wipe），期间焦点保持死锁，不随前景人物跟焦。
> 警报响起后，执行硬切（Cut）。焦段切换至85mm中长焦镜头，机位置于正前方，呈正面中近景双人构图。焦点绝对锁定云徽与晚照的面部，不加任何多余的机位运动。

提炼：遮挡是层次和离场调度，不一定是转场；是否抢焦明确写。警报作为剪切点，运动镜切到稳定近景，让表情接管叙事。

### P2 / SC-插播2 / v-OIIEOxkliY：人物停了，摄影机略迟一步

原段：

> 人物停步转身时，机位保持惯性向左微推后缓停（Slow Stop），随后执行平滑的景深切换（Rack Focus）由前景人物转移至后景远处的能量月牙。

提炼：侧移跟人 → 人物先停 → 摄影机惯性缓停 → 拉焦远景。镜头有速度包络，远处事件由人物发现，适合插播反应、远景异动和悬念。

### P1 / LX10 / v-PdfCfQRzln：从手中物件到城市尺度

原段：

> 随后机位进行平滑的环绕跟拍（Arc Shot），绕至池来身后的越肩大角度俯拍构图（OTS High Angle）。最后，镜头执行平滑且跨度极大的景深切换（Rack Focus），焦点从前景的池来切至极远景下方地面驶入城墙的车队，稳定落幅。

提炼：通讯器细节 → 面部 → 越肩俯瞰 → 渺小车队，完成“个体—职责—城市”的尺度展开。先让远景目标进入画面再拉焦；拉焦不会让几公里外的车队自动变大。

## 4. 高速动作：跟随、掠过、减速和急停都写清

### P3 / SC11-4 / v-0e1FMAHmUG：动作驱动速度包络

原段：

> 斩击爆发时执行平滑景深切换（Rack Focus），随后机位执行猛烈的前推跟拍（Fast Push In）10米并伴随平滑减速至缓停（Slow Stop）。
> 27.5s人物再次弹射时，机位配合动作二次执行爆炸式前推跟拍，最后随人物脚部擦地执行物理急停（Hard Stop），保持微震落幅。

提炼：攻击触发前推；角色出画时明确镜头接管冲击波；再次突进才二次加速；擦地触发急停，抖动随后衰减。速度感来自主体与背景相对运动、贴身距离、前景掠过和停顿，不只是反复写“极速”。

可复用段（示范改写，需替换秒数）：

~~~text
35mm，人物侧后近景，保持同向跟随。0–0.8s蓄力时机位稳定；0.8s蹬地触发前推，至1.8s向前移动6米；1.8–2.6s减速，人物越过画面右侧，焦点转向攻击沿途的环境反馈；2.6–3s缓停，保留烟尘继续前冲。摄影机不跟随每一片碎屑摆动。
~~~

### P3 / SC11-7 / v-xRxM0ID02j：高密度动作仍限定次数

原段标题：“瞬身突进清场斩击（必须斩出且仅斩出1刀）”；另限定“升格只能为1s，石板射出前必须结束升格恢复常速”。

提炼：主体高速时，把唯一主动作、刀数、持刀手、升格区间和恢复常速节点写硬。环境冲击、衣料延迟属于同一动作的反馈，不另造一次斩击。1帧/3帧是成片显示时长意图，未给帧率时不要擅自换算绝对秒数。

## 5. 巨物和多角度：尺度参照比形容词有效

- **P1 LX10**：街面极低位看落脚 → 建筑内快切看结构坍塌 → 高空长焦环绕看背部 → 侧前低位看头部。每次切镜展示显形的不同阶段，不重复同一次落脚。
- **P2 SC9-2 / v-WQfNolqMMU**：主战场释放月牙 → 远处人物越肩观察 → 城墙角度 → 跑动人物侧面同速跟随。远景能量形状、方向与发生时刻要一致；若重看同一瞬间，标明同步多视点或回看。
- **P3 SC17-4 / v-iI2jSph2WI**：近景踢斧 → 高空远景看斧压过镜头 → 低位长焦环绕看命中，再展示终结效果。跨镜保持A/B斧身份、锁链路径、发射点与目标受击方向。

可复用结构：近景建立动作起因 → 中远景读飞行轨迹 → 大全景确认结果。人、楼、城墙、云层作为比例尺；长焦采用较远机位取得压缩感，前中景遮挡提供深度参照。摄影机绕目标移动才产生环绕视差；原地摇摄不等于环绕。

## 6. 特效：本体分层 + 环境反馈 + 时间顺序

### P1 LX10 的显形

原段：

> 前缘：背景发生透明折射和空间拉伸，先勾出身体轮廓。
> 中层：发光裂纹和冷蓝色能量丝沿轮廓爬行，虚空膜卷曲剥落。
> 后缘：暗粒子逆向凝聚，半透明表面迅速转化为稳定实体材质。

提炼：可见轮廓先于实体；前缘、中层、后缘承担不同变化。巨兽边走边显形，实体化后的脚才触发踩踏反馈。迁移到新特效时，写材料转化过程及方向，不只更换颜色。

### P3 SC15-2 / v-mG6T5nFYUJ 的接触冲击

原段：

> 接触瞬间，周围空气短促压缩，背景云纹出现透镜状挤压，随即爆开薄而锋利的冲击环；环缘裹着被压白的云雾，按透视呈现圆环或椭圆，迅速扩张、变薄、消散。连续攻击各自触发独立震荡，上一击余波衰减时下一击立即进入。

提炼：接触 → 压缩 → 环爆 → 扩张衰减；同时保留攻击者反冲、受击者偏转、载人角色抓握和衣料迟滞。拍摄角度改变，冲击环投影也改变。

### P3 SC17-4 的终结大招

本体按“巨斧虚影 → 十字能量维持 → 延迟0.5s后三层不同高度/半径的环同时爆开”编排；环境另写风压、废墟碎屑、能量外涌、机身震颤。落幅以飞来的残块物理遮挡收束。复用时把“三层位置”与“先后时刻”分开，避免把三环齐爆误写成逐环延迟。

原作有意黑屏时，负向词改为“禁止无因黑屏；允许本镜指定遮挡黑场”，不要正向要求黑场、负向又无条件禁止。

## 7. 表演和声音：动作之后留下反应时间

### P3 SC12-1 / v-8exPbbnSLT

白猫面部超近景缓慢后拉，引入晚照腿部与城墙；跟白猫视线上摇给晚照反应，再随拉弓下摇回白猫。笑点依靠遮挡、误会、识别、态度转变的顺序，而非叠加夸张表情。弓箭“消解成能量（不是射出）”锁定动作结果。

### P3 SC15-2

搏斗后保持飞行，让晚照听到台词中段才出现躯干收缩、转头和反胃；穷奇话没说完就被反应打断，镜头减速让两者出画。可迁移的是“台词触发微动作—动作打断对白—出画收尾”，不是照搬该笑话。

声音写法：台词处直接绑定说话者声线；高空风噪、无线电失真、接触拟音、余音各有空间来源。远处爆炸与近景表演需要决定是否有传播延迟；动作点短暂静默必须占时。无BGM是这些案例的创作选择，不覆盖用户新的声音需求。

## 8. 资产写法：身份、造型、视图和声音分工

资产提示词完整原文见 [资产生成原文](029-asset-prompts.md)，节点及各镜锁定段见 [资产档案](029-assets.md)。

- **双基准**：云徽、宿妄、剑狞设定图明确由半身/面部图负责脸、发、眼、肤质，由全身图负责比例、服装结构与材质。视频再声明只参考造型，不继承资产背景和打光。
- **设定板布局**：左侧面部/半身特写，右侧全身正背视图；保持同人同衣、自然站姿、手脚完整。16:9是该类设定板实例，不强制所有资产横版。
- **可见性不是复制粘贴**：云徽正面露左腿腿环，背面被后裙片遮住，只见裙边以下长袜。共享服装结构，但不同视角有不同遮挡。
- **材质分开描述**：云徽深蓝哑光绒面与黑色绑带；晚照淡紫衬衫、灰针织、半透明层裙、黑靴；宿妄薄纱、丝质和金属装饰分别约束反射与垂坠。以上均来自文字，未以图片核验。
- **状态变体**：云徽全身/半身/持刀比例；池来普通白衣与战斗装；巨龟普通、冻结、玄武；运输车开门/关门。镜头选用相应变体，不把所有版本拼到一个人或道具上。
- **武器拓扑**：长直刃—加长刀柄—尾坠刚性连接；链斧写腰环—锁链—斧头的端点和数量。人物先落地、锁链随后、斧头最后落地，是重量与迟滞的写法。

整理后的资产段模板：

~~~text
· <角色>：身份基准 {{Node "面部节点"}}；服装/体态基准 {{Node "全身节点"}}。仅参考<范围>，不继承<背景/打光>。本镜采用<状态变体>；<左右不对称结构及视角遮挡>。声线 {{Node "音频节点"}}。
· <道具>：{{Node "道具节点"}}，数量<值>，尺寸/持握比例<值或参考>，连接关系<端点链>；允许变化<项>，禁止变化<项>。
· <场景>：{{Node "场景节点"}}，世界地标<坐标关系>，本机位看到的屏幕方向<关系>；环境时间与光照以本镜为准。
~~~

## 9. 原文可学，但这些错误不继承

1. **引用类型错配**：P3 SC15-2 把音频节点用于城墙、把图片节点用于声线，且存在空引用。查本项目节点实际类型与输入连线，不能按正文称呼直接信任。P3 SC16-3 有台词绑定池来图片的情况。纠正后再提交生成。
2. **不同版本不是同一设定**：P1 LX10 城墙宽50米，P3 SC12-1宽30米；P3 SC16是5链5刃，SC17转为两柄链斧。按用户选定段落维护版本，不合并成万能资产表。
3. **时间重叠/缺口**：P3 SC15-2镜1标题0–6s、下镜5.5s开始，镜3标题到19s而子段到23s；P2 SC3-2摄影机段有15–20.5s与19–23s重叠；P3 SC16-3镜2标到24s，明确子段只到23s，末尾余音应补入明确区间。
4. **方向冲突**：P3 SC11-7终结段先规定人物身后/画面左侧无兽，随后又写兽群全挤在最左侧。先定世界坐标，再逐机位映射屏幕方向；不要靠“锁死”重复矛盾。
5. **速度距离不符**：SC11-7写300km/h冲过800米，300km/h约83.3m/s，正常需9.6s；若只有1s画面，必须改速度、距离，或说明时间压缩/跳切。
6. **摄影术语混用**：Rack Focus是焦点转移，不等同景深扩大；Tilt是机位原地俯仰，不是机位升降；Pan不等同Arc；Crash Zoom是变焦突进，不等同摄影机前移。原文“广角透视压缩”“仰拍（High Angle）”“Static同时前推”等需改成一致表述。
7. **修订版保留身份**：无提示词的结果视频不冒充完整案例。名称含“备选”“bug”“去字幕”只作为版本线索，未观看成片不能认定哪个成功或失败。

写完检查：资产引用类型与连线、状态/数量、起落幅、焦点对象、运镜路径、快切计时、常速/升格切换、声画触发点。原段是参考材料，最终稿应消除冲突。
