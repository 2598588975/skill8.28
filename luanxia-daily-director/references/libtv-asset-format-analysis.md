# LibTV 画布资产与提示词格式分析

画布：[打开项目](https://www.liblib.tv/canvas?spaceId=6555479&projectId=494bce207e004f878be78bedf74bda5a)

提取方式：LibTV 官方 CLI，只读查询；没有修改、运行或新增任何节点。

## 1. 资产概况

画布共 44 个节点：

| 类型 | 数量 | 主要用途 |
| --- | ---: | --- |
| 分组 | 5 | 分镜与场景、道具、乱雪、云徽、晚照 |
| 图片 | 29 | 角色设定、多视图、场景、武器、小道具、分镜参考 |
| 音频 | 3 | 三位角色的独立声线样本 |
| 视频 | 7 | WX1–WX6 生成结果，以及 2 秒黑屏输入 |

### 常见素材规格

- 角色全身/多视图：约 941×1672、1152×2048、1536×2048，PNG 为主。
- 场景/武器：约 3376×1400 或 3376×1440 的超宽 PNG，强调空间纵深和侧视轮廓。
- 小道具：约 1086×1448 或 1448×1086。
- 声线：MP3，每位角色单独一条，时长约 4.3–5.9 秒。
- 视频参考：2.02 秒、1920×1080 的 MP4 黑屏资源。
- 生成视频：Seedance 2.5、`mixed2video`、21:9、720p、声音开启；主要为 24 秒或 30 秒。

## 2. 提示词共同结构

六份视频提示词虽然剧情不同，但共享同一骨架：

1. 剧情摘要与高光动作。
2. 成片要求：真人/动画、画幅、摄影机基底、声音和纯净画面要求。
3. 资产信息：通过 `{{Node …}}` 绑定角色、场景、道具和声线。
4. 最高优先级锁定：世界坐标、左右位置、角色状态、数量、持物手和禁用项。
5. 秒级分镜：镜号、时间、景别、运镜、摄影参数、画面动作链。
6. 对白模块：台词、角色、情绪、时间点、声线。
7. 音效层、物理接戏和负向提示词。

## 3. 镜头怎么写

### 动作镜头

- 常用 2–6 秒一镜。
- 镜内继续拆成 0.2–1.5 秒的动作节拍，用 `→` 写连续动作。
- 不只写“打斗”，而是写：攻击起点 → 轨迹 → 接触点 → 双方受力 → 动作分离 → 环境余波。
- 摄影机常见低机位、荷兰角、后拉跟拍、贴地摇镜、环绕和短暂升格。

### 对白镜头

- 常用 5–15 秒长镜，可在镜头下拆 A/B/C 快切段。
- 单列焦段、光圈、机位、焦点切换和推拉摇移。
- 画面重点是视线、手部小动作、表情变化、口型和人物调度。
- 台词绑定角色声线与时间点，音效层单独写。

## 4. 画面怎么写

建议每个镜头固定为：

```text
镜头 01 | 00:00–00:04.5 | 4.5s | 中景/低机位 | 连续
【摄影机】焦段、机位、运动、构图、景深
【起幅】人物左右、朝向、持物、前中后景
【画面】动作 A（1.2s）→ 反馈 B（0.8s）→ 动作 C（2.5s）
【人物表演】视线、重心、表情、呼吸、口型
【对白】说话人｜台词｜语气｜时间点
【音效】拟音、环境声、声音方向
【落幅/接戏】镜尾状态与下一镜承接条件
```

摄影机栏只写“镜头如何看”；画面栏只写“观众实际看到什么”。不要用“高级、震撼、电影感”代替动作和构图。

## 5. 原画布中值得修正的问题

- 个别节点的模型设置时长与提示词分镜总时长不一致。
- 个别全局左右位置锁定与后续镜头描述冲突。
- 个别镜头内部子动作时间相加后超过镜头标注时长。
- 相似节点可能复用提示词，但资产与生成设置不同。

因此整理后的 Skill 增加了时长、坐标、数量、资产引用和物理接戏五项强制检查。
