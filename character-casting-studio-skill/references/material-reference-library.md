# Public Material Reference Library

This public repository intentionally contains no user-uploaded face images or private reference files.

Use this catalog to organize local or explicitly authorized materials at runtime. Do not commit private photos, clipboard screenshots, personal portraits, or source files containing identifying information.

## Usage Rules

- Use at least three complementary source categories for production-grade characters: face structure, styling/body/pose, and world/light/material.
- Assign different face sources to different characters in a batch. Do not feed one face source to every character.
- Extract broad visual genes only: face geometry, eye and brow structure, hair behavior, skin texture, age cues, expression, silhouette, and lighting.
- Never copy a single person's identity, exact facial arrangement, signature styling, or recognizable likeness.
- For a batch, build an identity matrix and state that the characters are distinct unrelated individuals.

## Recommended Local Source Categories

### Face and Person

- Broad face geometry and facial-plane references
- Eye and brow spacing references
- Nose and lip proportion references
- Hair texture and hairline references
- Natural skin texture and age-cue references

### Wardrobe, Body, and Pose

- Garment construction and fabric references
- Body silhouette and posture references
- Jewelry, accessories, props, and occupation cues
- Movement, gesture, and casting-pose references

### World, Material, and Light

- Architecture and location references
- Film stills and photographic lighting references
- Fabric, metal, leather, paper, stone, and wood textures
- Color palette and background separation references

## Source Map Format

Before generation, record broad contributions without identifying information:

```text
Source A = cheekbone and brow structure
Source B = hair texture and skin detail
Source C = garment construction and accessory logic
Source D = background material and lighting
```

Perturb facial proportions, replace identity anchors, and add new memory points so the output is an original person rather than a composite copy.
